# GrimReap — estado persistente do ciclo Fable

**Estado geral:** `READY_FOR_REVIEW`  
**Nome do jogo:** GrimReap  
**Reino dos continentes:** Reino de GrimReap

## Stack real do projeto

- Cliente web/mobile: HTML, CSS e TypeScript; mapas locais renderizados em Canvas 2D isométrico.
- Backend de jogo: Kotlin/Ktor, incluindo autenticação, regras autoritativas e WebSocket multiplayer por zona.
- Toolchain: JDK 17+, Gradle Wrapper backend 8.10.2, Node 22 LTS/npm 10+, Python 3.14 estável com Pillow 13.0.0 para geração de assets.
- Mobile: projeto Android gerado por Capacitor em `mobile/android`; APK de debug compilado com JDK 17/API 34, mas ainda não testado em dispositivo.
- `backend/go-engine/main.go` continua protótipo isolado e não participa do fluxo autoritativo atual.
- Arte Bakin-compatible: geração pixel art procedural local em Python/Pillow, sem chamadas a API externa.

## Comandos de repetição

Na raiz do projeto:

```powershell
uv run --python 3.14 --with-requirements ferramentas\requirements.txt ferramentas\gerar_assets_bakin_local.py
uv run --python 3.14 --with-requirements ferramentas\requirements.txt ferramentas\fable5_vision_check.py
.\run-tests.ps1
```

Para verificar o protótipo Go isolado, dentro de `backend\go-engine`:

```powershell
go test main.go
go vet main.go
```

Para compilar o Android, dentro de `mobile\android`, use JDK 17 e Android SDK API 34:

```powershell
.\gradlew.bat :app:assembleDebug
```
